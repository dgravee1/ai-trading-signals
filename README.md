# دليل تشغيل ورفع منصة التوصيات الذكية 24/7 على استضافة مجانية

هذا المشروع مبني بلغة Python (FastAPI) ويعمل في السيرفر على مدار الساعة (24/7) كل 5 دقائق حتى لو أغلقت هاتفك أو المتصفح.

## محتويات الملف المضغوط:
1. `main.py`: السيرفر الرئيسي والمجدول التلقائي (يعمل كل 5 دقائق).
2. `engine.py`: محرك جلب الأسعار الحية، الأخبار الاقتصادية، والربط مع Gemini AI.
3. `strategies.py`: محرك التحليل الفني الشامل (EMA 200, RSI, MACD, Bollinger Bands, Ichimoku, ATR).
4. `database.py`: قاعدة بيانات لحفظ التوصيات وتتبع وصولها للهدف أو وقف الخسارة.
5. `index.html`: واجهة الويب الاحترافية مع شارت TradingView التفاعلي.
6. `requirements.txt`: المكتبات البرمجية المطلوبة.

---

## خطوات الرفع على الاستضافة المجانية (Render.com) خطوة بخطوة:

### الخطوة 1: الحصول على مفتاح الذكاء الاصطناعي المجاني (Gemini API)
1. ادخل إلى موقع: https://aistudio.google.com/
2. اضغط على **Get API Key** ثم **Create API key** وانسخ المفتاح.

### الخطوة 2: رفع الملفات إلى GitHub
1. أنشئ حساباً مجانياً في موقع [GitHub.com](https://github.com).
2. أنشئ مستودعاً جديداً (New Repository) وسمّه مثلاً `ai-trading-signals`.
3. ارفع جميع هذه الملفات بداخله (فك الضغط عن ملف ZIP وارفع الملفات التي بداخله).

### الخطوة 3: التشغيل المجاني 24/7 على Render.com
1. ادخل إلى [Render.com](https://render.com) وسجل الدخول بحساب GitHub.
2. اضغط على **New +** ثم اختر **Web Service**.
3. اختر المستودع `ai-trading-signals` واضغط **Connect**.
4. في الإعدادات اكتب:
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn main:app --host 0.0.0.0 --port 10000`
   - اختر الخطة المجانية (**Free**).
5. انزل إلى قسم **Environment Variables** وأضف متغيراً جديداً:
   - **Key:** `GEMINI_API_KEY`
   - **Value:** (الصق المفتاح الذي نسخته في الخطوة 1)
6. اضغط **Deploy Web Service**. بعد دقيقتين سيعطيك الموقع رابطك الخاص (مثلاً `https://ai-trading-signals.onrender.com`).

## الخطوة 4 (مهمة جداً): كيف تجعله يعمل 24/7 حتى وهاتفك مغلق؟
الاستضافات المجانية تدخل في وضع السكون (Sleep) بعد 15 دقيقة إذا لم يفتح أحد الموقع. لمنع ذلك نهائياً:
1. ادخل إلى الموقع المجاني **[Cron-job.org](https://cron-job.org)** وأنشئ حساباً مجانياً.
2. اضغط على **Create Cronjob**.
3. في خانة **URL** ضع رابط موقعك متبوعاً بـ `/api/ping` هكذا:
   `https://ai-trading-signals.onrender.com/api/ping`
4. اجعل التوقيت **Every 5 minutes** (كل 5 دقائق) واضغط **Create**.

الآن سيرفرك سيبقى مستيقظاً 24 ساعة في اليوم، يحلل السوق كل 5 دقائق، ويسجل التوصيات في قاعدة البيانات حتى لو أغلقت هاتفك ليوم كامل!
